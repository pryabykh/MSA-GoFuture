### <a name="_b7urdng99y53"></a>**Название задачи: выбор регионов развёртывания**

### <a name="_uanumrh8zrui"></a>**Дата: 9 мая 2026**

### <a name="_3bfxc9a45514"></a>**Контекст**

Платформа GoFuture предоставляет высоконагруженный сервис заказа поездок с требованиями:

- обработка более 500 000 конкурентных поездок
- 99.99% доступности
- низкая задержка для пользователей в Юго-Восточной Азии
- устойчивость к региональным отказам
- возможность масштабирования и соблюдения локальных регуляторных требований.

Для выполнения этих требований необходимо развернуть платформу в нескольких географически распределённых регионах

### <a name="_3bfxc9a45514"></a>**Требования**

- Минимизация пользовательской задержки
- Исключение единой точки отказа на уровне региона
- Возможность межрегиональной репликации данных
- Соответствие локальным требованиям по хранению персональных данных
- Готовность к масштабированию и дальнейшему глобальному расширению

### <a name="_3bfxc9a45514"></a>**Решение**

Для развёртывания платформы GoFuture в Юго-Восточной Азии выбраны следующие регионы: Сингапур, Джакарта, Гонконг

### <a name="_3bfxc9a45514"></a>**Обоснование**

Сингапур:
- Региональный сетевой хаб с минимальной задержкой для стран Юго-восточной Азии.
- Высокая надёжность облачной инфраструктуры.
- Используется как основной регион обработки трафика и источник истины для критических данных.

Джакарта:
- Существенно снижает задержки для крупнейшега рынка региона.
- Позволяет обслуживать трафик независимо от Сингапура.
- Обеспечивает дополнительный уровень отказаустойчивости сервиса в случае сбоя в других регионах.

Гонконг:
- Используется для аварийного восстановления и резервного хранения данных.
- Позволяет обслуживать трафик независимо от Сингапура.
- Обеспечивает дополнительный уровень отказаустойчивости сервиса в случае сбоя в других регионах.
