### <a name="_b7urdng99y53"></a>**Название задачи: Схема геомаршрутизация пользователей**

### <a name="_uanumrh8zrui"></a>**Дата: 9 мая 2026**

### <a name="_3bfxc9a45514"></a>**Контекст**

Платформа GoFuture предоставляет высоконагруженный сервис заказа поездок с требованиями:

- обработка более 500 000 конкурентных поездок
- 99.99% доступности
- низкая задержка для пользователей в Юго-Восточной Азии
- устойчивость к региональным отказам
- корректная маршрутизация трафика

Пользователи подключаются с мобильных приложений и веб-интерфейсов, а бэкенд приложения развёрнут в нескольких
географически распределённых регионах.

### <a name="_3bfxc9a45514"></a>**Требования**

- Маршрутизировать пользователей в ближайший доступный регион.
- Минимизировать сетевую задержку
- Поддерживать автоматическое аварийное переключение.
- Исключить единую точку отказа на уровне входа в систему.

### <a name="_3bfxc9a45514"></a>**Решение**

Используется многоуровневая схема геомаршрутизации, состоящая из:

- Global DNS / Traffic Manager
- Global WAF
- Региональных API Gateway

### <a name="_3bfxc9a45514"></a>**Global DNS**

Функции

- Определяет регион пользователя по IP (GeoIP).
- Возвращает DNS-запись ближайшего доступного к подключению региона.

Принцип работы
- Клиент выполняет запрос к api.gofuture.com.
- GeoDNS определяет географическое положение клиента.
- Возвращается IP-адрес ближайшего региона


### <a name="_3bfxc[ADR_1.md](ADR_1.md)9a45514"></a>**Global WAF**

Функции:
- DDoS-защита (L3–L7).
- Ограничение подозрительного трафика.

### <a name="_3bfxc[ADR_1.md](ADR_1.md)9a45514"></a>**Региональный API Gateway**
Каждый регион содержит собственный API Gateway:

- принимает трафик только из Global WAF;

- rate limit,
- circuit breaking;
- маршрутизирует запросы в локальные сервисы.

### <a name="_3bfxc[ADR_1.md](ADR_1.md)9a45514"></a>**Альтернативы**

Синхронная репликация БД

Отклонена, так как:

- увеличивает latency пользовательских операций;
- критична к межрегиональным задержкам.
